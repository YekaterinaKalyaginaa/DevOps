# Скрапер цитат

Приложение на Node.js, которое использует Playwright и браузер Chromium для сбора цитат с сайта [Quotes to Scrape](https://quotes.toscrape.com/scroll) и сохранения их в формате JSON.

## Описание проекта

Скрапер собирает текст цитаты, имя автора и теги. Результат сохраняется в файл `out/result.json`.

Проект использует многоэтапную сборку Docker. Установка зависимостей, установка браузера и подготовка итогового образа выполняются в отдельных стадиях. Независимые стадии позволяют Docker BuildKit выполнять некоторые операции параллельно, если это возможно. Кэширование слоёв ускоряет повторную сборку при изменении только исходного кода.

## Используемые технологии

- Node.js 22 — среда выполнения JavaScript.
- Playwright — автоматизация браузера.
- Chromium — браузер, используемый для сбора данных.
- Docker и BuildKit — контейнеризация и сборка образа.
- GNU Make — запуск основных команд проекта.
- GitHub Actions — автоматическая проверка проекта.

## Локальная среда разработки

Для работы с проектом необходимы:

- Node.js 22 или совместимая более новая версия;
- Docker Desktop с запущенным Docker Engine;
- GNU Make;
- Git.

Основной исходный код находится в `src/scraper.js`. Настройки сборки и запуска Docker находятся в `Dockerfile`, `.dockerignore` и `Makefile`.

## Запуск проекта

Все команды выполняются из корневой папки проекта.

### Сборка Docker-образа

```bash
make build
```

Создаёт Docker-образ с именем `quotes-scraper`.

### Запуск скрапера

```bash
make run
```

Запускает контейнер и сохраняет собранные цитаты в файл `out/result.json` на компьютере.

### Проверка проекта

```bash
make ci
```

Выполняет сборку образа, запуск скрапера и проверку результата: файл должен существовать, быть непустым и содержать корректный JSON.

### Очистка

```bash
make clean
```

Удаляет образ `quotes-scraper` и каталог `out/`. Кэш сборки Docker сохраняется, чтобы при следующей сборке можно было повторно использовать неизменившиеся слои.

## Этапы сборки Docker

В `Dockerfile` используются три стадии.

1. **dependencies** — устанавливает зависимости Node.js с помощью `npm ci`.
2. **browser** — устанавливает браузер Chromium для Playwright.
3. **runtime** — формирует итоговый образ, устанавливает системные библиотеки, копирует зависимости и браузер из предыдущих стадий, а затем добавляет исходный код приложения.

Исходный код копируется ближе к концу Dockerfile. Поэтому при изменении `src/scraper.js` Docker может повторно использовать кэш зависимостей и браузера.

## Непрерывная интеграция (CI)

GitHub Actions запускает команду `make ci`. Она проверяет, что Docker-образ собирается, скрапер выполняется, а результат сохраняется и проходит проверку формата JSON.

Каталоги `node_modules/` и `out/` исключены из Git с помощью файла `.gitignore`.

## Формат результата

Файл результата: `out/result.json`.

Он содержит JSON-массив объектов со следующими полями:

- `text` — текст цитаты;
- `author` — имя автора;
- `tags` — массив тегов цитаты.
